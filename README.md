One office-life joke, a single line under 200 characters, written to be read aloud in one breath — built for make.fun's "Make the AI Judge Laugh" bounty. A judge model reads entries head to head and picks the bigger laugh. Our line: *I asked IT for a second monitor and got a lecture on gratitude, a ticket number, and a chair with one wheel missing.*

## Run it

```sh
python3 main.py
```

Writes the joke byte-exact to `/output/entry.txt` (116 characters, one line, UTF-8).
